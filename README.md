Selamat datang di repositori website portofolio interaktif **Fitra Romeo Winky**. Website ini dirancang khusus untuk memamerkan proyek unggulan, latar belakang keahlian di bidang Artificial Intelligence, Machine Learning, Computer Vision, NLP, Backend Web & Database, serta integrasi aplikasi Full-Stack.

---

## ✨ Fitur Utama

- 🌗 **Dual Theme System (Dark & Light Mode)**: Dukungan tema gelap dan terang secara dinamis dengan variabel warna khusus Slate & Sky Cyan.
- 💎 **Glassmorphism Navbar**: Sticky header dengan efek blur kaca, indikator status ketersediaan (🟢 *Available for Hire*), dan penjejak scroll aktif.
- 📱 **Desain Serba Responsif**: Tampilan yang dioptimalkan untuk perangkat Desktop, Tablet, hingga Smartphone (termasuk menu toggle seluler).
- 🖼️ **Pop-Up Detail Proyek Interaktif**: Kartu proyek dapat diklik untuk membuka jendela modal dengan gambar resolusi penuh, deskripsi detail, tag teknologi, dan tautan repositori.
- 📋 **One-Click Contact Action**: Salin nomor WhatsApp atau kirim pesan secara langsung dalam satu klik.

## 🚀 Cara Menjalankan Secara Lokal

1. **Clone Repositori ini**:
   ```bash
   git clone https://github.com/fitraaromeo/portfolio-web.git
   cd portfolio-web
   ```

2. **Install Dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan Development Server**:
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:5173/`

4. **Build untuk Produksi**:
   ```bash
   npm run build
   ```
